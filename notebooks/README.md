# Notebooks

Ce dossier est destiné aux notebooks d'exploration, d'entraînement et d'analyse.

## Versionnement

- Les notebooks `.ipynb` sont autorisés dans le dépôt.
- Pour les notebooks volumineux, Git LFS est utilisé (voir `.gitattributes`).

## Bonnes pratiques

- Nettoyer les outputs avant commit.
- Garder les notebooks reproductibles (cellules exécutables de haut en bas).
